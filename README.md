# Employee Performance Analysis

## 📊 Project Overview

Employee Performance Analysis is an end-to-end Data Analytics project
designed to analyze employee information, salary, performance,
department distribution, location and employment status.

The project uses Python, Excel, SQL and Power BI to clean, analyze,
visualize and present meaningful business insights.

---

## 🎯 Project Objective

The main objectives of this project are:

- Analyze employee data
- Clean and prepare the dataset
- Analyze employees by department
- Analyze salary distribution
- Analyze employee performance
- Analyze employee locations
- Analyze Active and Inactive employees
- Identify missing performance scores
- Create an interactive Power BI dashboard
- Generate business insights

## 🔍 Key Business Insights

### Department

IT has the highest number of employees with 339 employees.

### Performance

IT has the highest average recorded performance score at 3.73.

### Salary

HR has the highest average salary at approximately ₹6.47K.

### Location

Los Angeles has the highest employee count with 340 employees.

### Employee Status

There are 759 Active employees and 241 Inactive employees.

### Data Quality

498 employees have missing Performance Scores.
This should be investigated before using performance data
for important business decisions.

---

## 💡 Recommendations

- Improve the collection of employee performance scores.
- Investigate missing performance data.
- Monitor employee performance by department.
- Analyze salary differences with experience and job roles.
- Monitor Active and Inactive employee trends.
- Regularly refresh the Power BI dashboard.
